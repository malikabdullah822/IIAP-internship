# Airport Flight Tracker - Week 2: Day 5 (Mini Project)

## Topics Covered
- Practice problems & DOM selection
- Array management and loop iteration (`forEach` and `for` loops)
- Event listeners (`click` event)
- Conditional logic & input validation

## Implementation Summary
- **HTML (`index.html`):** Provides the structural dashboard layout featuring a search input box, check status button, feedback result message, and an active terminal flights list container.
- **CSS (`style.css`):** Applies clean card container styling, centering layouts, custom color accents, and responsive input/button padding.
- **JavaScript (`script.js`):** Implements DOM element selection, manages an array of active flights, renders lists dynamically using loops, attaches click event listeners, validates empty inputs, and executes conditional search checks.
