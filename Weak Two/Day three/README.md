# Airport IT Internship - Week 2: Day 3 (Loops, Events, and Click Counter)

## Overview
Day 3 of Week 2 focuses on executing repetitive tasks using loops and handling interactive user events in JavaScript. This session builds a real-time airport passenger check-in click counter dashboard to practice DOM event listeners and dynamic state management.

---

## Topics Covered
* **Loops:** Automating repetitive execution blocks in JavaScript.
* **Events (`click`, `submit`):** Capturing and responding to user interactions on the web page.
* **`while` & `do-while` Loops:** Managing conditional loop execution based on specific counters.
* **Looping over Arrays:** Iterating through structured lists of data (such as terminal gates) programmatically.
* **Adding Event Listeners:** Attaching interactive behavior to DOM elements safely.
* **Hands-on Project:** Building an interactive passenger check-in click-counter application.

---

## Implementation Summary
* **HTML (`index.html`):** Provides the structural dashboard layout featuring a main title, a dynamic counter display element, and an interactive action button.
* **CSS (`style.css`):** Applies clean styling, centering layouts, custom color accents, and smooth hover transition states for UI elements.
* **JavaScript (`script.js`):** Implements event listening to track button clicks, updates state variables dynamically, logs operational data to the console, and demonstrates array/while-loop iterations.
