# Airport IT Internship - Week 2: Day 4 (Functions, Form Validation, and Custom Messages)

## Overview
Day 4 of Week 2 focuses on creating reusable blocks of code using JavaScript functions and implementing robust form validation rules. This hands-on session builds an interactive airport staff signup dashboard that validates user credentials, checks password length constraints, and provides real-time custom feedback messages.

---

## Topics Covered
* **Functions:** Grouping reusable blocks of logic to avoid code repetition.
* **Form Validation:** Inspecting and verifying user input data before form submission.
* **Function Declarations vs Expressions:** Understanding different structural ways to write and define functions in JavaScript.
* **Parameters, Arguments, & Return Values:** Passing data into functions and capturing processed results.
* **Custom Validation Messages:** Generating dynamic success or error feedback based on user inputs.
* **Hands-on Project:** Building an interactive staff registration signup validation workflow.

---

## Implementation Summary
* **HTML (`index.html`):** Establishes the structural dashboard layout featuring a clean card container, an input form with username/password fields, a submit button, and a dynamic feedback message display area.
* **CSS (`style.css`):** Applies modern flexbox alignment, centered container styling, smooth button hover states, and clear typography.
* **JavaScript (`script.js`):** Implements event prevention on form submission, utilizes custom validation functions with parameters/return values, checks input constraints, and updates the UI dynamically with color-coded success or error indicators.
