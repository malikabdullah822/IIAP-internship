# Airport IT Internship - Week 1: Day 3 (Box Model, Lists, and Pricing Tables)

## Overview
Day 3 of Week 1 focuses on mastering the CSS Box Model, content spacing, list styling types, and building structured components like pricing tables. This hands-on session develops an interactive feature overview and multi-tier pricing card layout tailored for IT infrastructure services.

---

## Topics Covered
* **CSS Box Model:** Controlling layout dimensions using `content`, `padding`, `border`, `border-radius`, and `margin`.
* **Lists Styling:** Customizing unordered lists (`circle`) and ordered lists (`lower-alpha`) with proper spacing and nested formatting.
* **Flexbox Layouts:** Organizing child elements side-by-side using `display: flex`, `justify-content: center`, and custom gap spacing.
* **Card Modifiers & States:** Applying feature highlights, subtle borders, shadows, and hover transitions for call-to-action buttons.
* **Hands-on Project:** Developing a structured main wrapper container containing system features, deployment steps, and standard/pro pricing plans.

---

## Implementation Summary
* **HTML (`index.html`):** Establishes semantic content boxes containing unordered and ordered lists, alongside a dedicated pricing section featuring standard and featured pro plans.
* **CSS (`style.css`):** Applies global box configurations, background styling, specific padding/margin rules, list adjustments, flexbox pricing alignments, and button interactive states.
