# Airport IT Internship - Week 1: Day 1 (HTML & CSS Basics)

## Overview
Day 1 of Week 1 focuses on introducing foundational web development concepts, including setting up an HTML5 document and connecting an external CSS stylesheet. This hands-on session builds a simple welcome page introducing the airport IT internship journey, featuring basic styling, background color adjustments, and typography rules.

---

## Topics Covered
* **HTML Structure:** Setting up essential elements like `<!DOCTYPE html>`, `<head>`, `<meta charset="UTF-8">`, and linking an external stylesheet via `<link rel="stylesheet" href="style.css">`.
* **CSS Styling:** Applying global body background coloring, centering text alignment, and adjusting padding offsets.
* **Typography & Colors:** Controlling font families, font sizes, and custom text colors for headings and paragraphs.
* **Hands-on Project:** Developing a clean, centered introductory page for the airport IT internship program.

---

## Implementation Summary
* **HTML (`index.html`):** Establishes the basic document layout containing a main welcome heading and an introductory paragraph about learning HTML and CSS.
* **CSS (`style.css`):** Applies styling rules to the `body` (black background, Arial font, centered layout, top padding), headers, and paragraph text elements.
