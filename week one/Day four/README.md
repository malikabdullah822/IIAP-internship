# Airport IT Internship - Week 1: Day 4 (Forms, Flexbox Layouts, and UI Design)

## Overview
Day 4 of Week 1 focuses on building responsive layout structures using CSS Flexbox and implementing functional HTML contact forms. This hands-on session builds an interactive support ticket and contact dashboard tailored for airport IT infrastructure operations, utilizing modern input types and structured styling.

---

## Topics Covered
* **HTML Forms:** Structuring user input elements utilizing `text`, `email`, dropdown `select`, `radio`, and `checkbox` types.
* **Accessibility & Labels:** Associating form labels properly to improve user experience and accessibility.
* **CSS Flexbox:** Applying layout properties like `display: flex`, `justify-content: space-between`, `align-items: center`, and `gap` to build scalable navigation bars and aligned form controls.
* **Interactive UI States:** Implementing hover states, focus outlines, and responsive container constraints to refine styling.
* **Hands-on Project:** Developing a responsive Airport IT support contact form card and navigation header.

---

## Implementation Summary
* **HTML (`index.html`):** Establishes a semantic layout including a flexbox navigation bar and a main container holding a structured contact form card with input fields, select dropdowns, priority options, and terms acceptance.
* **CSS (`style.css`):** Applies custom global body setup, professional color schemes, flexbox alignments for navigation and radio groups, box-sizing rules, and focus-state highlights.
