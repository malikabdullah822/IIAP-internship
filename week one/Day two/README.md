# Airport IT Internship - Week 1: Day 2 (Intermediate HTML & CSS, Color Formats, & Typography)

## Overview
Day 2 of Week 1 focuses on exploring intermediate HTML and CSS concepts, including setting up custom web fonts via Google Fonts, using internal anchor jump links, incorporating optimized images with accessibility attributes, and applying different CSS color formats (Hex, RGB, and HSL). This hands-on session builds an intermediate structured profile page for the airport IT internship program.

---

## Topics Covered
* **Anchor Links & Navigation:** Implementing internal jump links (`href="#about"`) and external links with security attributes (`target="_blank"`).
* **Typography & Web Fonts:** Loading and applying custom fonts (`Poppins`) using Google Fonts integration.
* **CSS Color Formats:** Utilizing different color models including Hex codes, RGB, and HSL to style elements and backgrounds.
* **Image Optimization & Accessibility:** Integrating images with descriptive alternative text (`alt`), responsive sizing, and shadow effects.
* **Hands-on Project:** Developing a structured navigation header, main headings, introductory paragraph sections, and styled image containers.

---

## Implementation Summary
* **HTML (`index.html`):** Establishes navigation anchor links, internal section IDs, main semantic tags (`<header>`, `<main>`), and an optimized image container.
* **CSS (`style.css`):** Applies custom web fonts, global body text styling, HSL and RGB background rules, navigation padding, and image responsiveness properties.
