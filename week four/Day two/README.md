# Islamabad International Airport - Gate Status Toggle System (Week 4, Day 2)

A React-based interactive web application developed as part of the IT Web Development Internship program at Islamabad International Airport. This project demonstrates core React concepts including functional components, parent-child composition, props, event handling, and state management.

---

## 🚀 Project Overview
The **Gate Status Toggle System** allows airport ground staff to monitor and toggle the operational status of boarding gates (e.g., Gate A-07) dynamically without requiring a full page reload.

---

## 📚 Key Concepts Covered (Day 2)
1. **Components & JSX:** Building reusable UI components using XML-like syntax inside JavaScript.
2. **Functional Components:** Creating modular, stateless and stateful functional components.
3. **Parent/Child Composition:** Structuring the application hierarchy where the Parent component manages core logic and passes data down.
4. **Props & Event Handlers:** Passing variables and handler functions from Parent components to Child components via props.
5. **State Management & Toggle Logic:** Utilizing React's `useState` hook to manage boolean states and trigger instant UI re-renders.

---

## 🛠️ Tech Stack
* **Framework:** React.js (with Vite)
* **Styling:** Custom CSS3 (Flexbox, Responsive Design, Dynamic Badges)
* **Version Control:** Git & GitHub
* **Development Tool:** Visual Studio Code
