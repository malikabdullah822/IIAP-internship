# Islamabad International Airport - Flight Information & Gate Status Dashboard (Week 4, Day 3)

A React-based interactive web application developed as part of the IT Web Development Internship program at Islamabad International Airport. This project demonstrates advanced component composition, props utilization, and conditional rendering techniques in React.

---

## 🚀 Project Overview
The **Flight Information & Gate Status Dashboard** enables airport staff to view dynamic flight cards featuring conditional status badges (On Time, Delayed, Boarding) and special VIP lounge indicators.

---

## 📚 Key Concepts Covered (Day 3)
1. **Props:** Passing dynamic data (flight numbers, destinations, gates, statuses) from Parent components to Child components.
2. **Conditional Rendering:** Utilizing JavaScript logical operators (`&&`) and ternary operators (`? :`) to render UI elements based on state or prop conditions.
3. **Component Composition:** Building reusable modular cards (`FlightCard`) inside a main dashboard layout (`App`).
4. **Dynamic Styling:** Applying conditional CSS classes based on prop values (e.g., VIP borders and status badge colors).

---

## 🛠️ Tech Stack
* **Framework:** React.js (with Vite)
* **Styling:** Custom CSS3 (Flexbox, Dynamic Badges, Responsive Layout)
* **Version Control:** Git & GitHub
* **Development Tool:** Visual Studio Code
