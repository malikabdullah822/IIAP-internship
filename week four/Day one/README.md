# Airport IT Internship - Week 4: Day 1 (React & Vite Counter Application)

## Topics Covered
* **Introduction to React & Vite:** Setting up a modern, fast front-end development environment using Vite.
* **Component-Based Architecture:** Understanding `App.jsx` and structural component rendering.
* **React Hooks (`useState`):** Managing local state dynamically to handle interactive UI changes.
* **Event Handling:** Implementing arrow functions (`handleIncrement` & `handleDecrement`) to capture user clicks.
* **Conditional UI Logic:** Ensuring counters do not drop below zero using conditional boundaries.

---

## Implementation Summary
* **React Counter App (`App.jsx`):** Provides an interactive dashboard utilizing React functional components and the `useState` hook to manage real-time increment and decrement actions.
