# Islamabad International Airport - Filterable Flight Schedule Dashboard (Week 4, Day 4)

A React-based interactive web application developed as part of the IT Web Development Internship program at Islamabad International Airport. This project demonstrates advanced list rendering using the `.map()` method, unique key management, and real-time client-side search filtering.

---

## 🚀 Project Overview
The **Filterable Flight Schedule Dashboard** allows airport staff and passengers to search and filter live flight records dynamically by flight number or destination city using a responsive tabular interface.

---

## 📚 Key Concepts Covered (Day 4)
1. **Simple Components:** Breaking down complex UIs into clean, modular child components (`FlightListItem`).
2. **Lists & Arrays:** Managing structured sets of flight data using JavaScript arrays.
3. **Component File Organization:** Structuring React source files properly for scalability and maintenance.
4. **Rendering Lists with `.map()`:** Iterating through data arrays to automatically generate JSX elements.
5. **Keys in Lists:** Assigning unique `key` props to list items to optimize React's virtual DOM reconciliation and rendering performance.
6. **Hands-on Filtering:** Implementing interactive search inputs combined with JavaScript `.filter()` and state hooks (`useState`) to update views in real time.

---

## 🛠️ Tech Stack
* **Framework:** React.js (with Vite)
* **State Management:** React Hooks (`useState`)
* **Styling:** Custom CSS3 (Tables, Flexbox, Search Inputs, Responsive Design)
* **Version Control:** Git & GitHub
* **Development Tool:** Visual Studio Code
