# IIAP Internship - Week 5 Day 2 Portal

A modern React-based web application developed as part of the IT Web Development Internship tasks at the Pakistan Airports Authority, Islamabad International Airport.

## Author
* **Name:** Abdullah

## Project Overview
This project demonstrates core React concepts including state management (`useState`), event handling, form submission prevention (`preventDefault()`), strict validation (`@gmail.com` email format checks), read-only field constraints, and complete CRUD (Create, Read, Update, Delete) operations for participant registration records.

## Features
* **Participant Registration Form:** Collects full name, email address, user role, airport department, and shift timings.
* **Strict Email Validation:** Ensures email addresses follow the exact `@gmail.com` format and rejects trailing characters or dots.
* **Locked Department Field:** Configured with read-only attributes to maintain a fixed department designation ("Aviation Office").
* **Interactive Records Directory:** Displays all submitted entries dynamically with real-time counters.
* **Edit & Delete Operations:** Allows users to modify existing entries or remove unwanted records from the collection seamlessly.
* **Responsive UI & Animations:** Styled with modern CSS gradients, smooth transitions, and intuitive notification banners.

## Technologies Used
* **React (JavaScript Library):** Component-based architecture and state hook management.
* **HTML5 & JSX:** Semantic markup structures.
* **CSS3:** Custom styles, Flexbox layout, keyframe animations, and modern card styling.
* **Visual Studio Code:** Development environment and source code management.
