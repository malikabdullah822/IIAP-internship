# IIAP IT Internship - Day 4 Project

## Overview
Developed as part of the IT Web Development Internship at the Pakistan Airports Authority (Islamabad International Airport - IIAP). This project strictly implements Day 4 learning requirements, including project structure refactoring, component organization, hooks, and **Lifting State Up**.

## Topics Covered & Features
- **Project Structure & Organization**: Clean modular separation into `FormComponent` and `DirectoryComponent`.
- **Lifting State Up**: Centralized state management in parent `App` component and passing handlers downwards via props.
- **Hooks & State Management**: Extensive use of React `useState` for inputs, record lists, edit tracking, and alerts.
- **Connecting Components**: Seamless integration between form submission handlers and directory listings.
- **Strict Form Validation**: Mandatory checks, strict `@gmail.com` filter, and custom `EMP-XXXX` Employee ID regex validation.
- **Full CRUD Operations**: Dynamic Create, Read, Update, and Delete capabilities.
- **Mobile Responsiveness**: Perfectly centered layout scaling seamlessly across mobile devices with zero horizontal overflow.

## Tech Stack
- React.js (Vite)
- JavaScript (ES6+)
- CSS3 (Flexbox & Responsive Media Scaling)
