# IIAP Internship - Advanced React Portal (Days 1 to 3)

A professional, fully validated React-based web application developed as part of the IT Web Development Internship tasks at the Pakistan Airports Authority, Islamabad International Airport.

## Author
* **Name:** Abdullah

## Project Overview
This project combines core concepts covered across Days 1, 2, and 3 of the internship:
* **Controlled Inputs (`useState`):** Managing multi-field input states dynamically.
* **Form Submission & Prevention (`preventDefault()`):** Handling form events cleanly without full-page reloads.
* **Rigorous Validation:** Required field checks, string length restrictions, strict Gmail pattern checks (`@gmail.com`), and employee ID RegEx matching (`EMP-XXXX`).
* **UI Feedback Banners:** Dynamic success and error notification alert banners.
* **Complete CRUD Operations:** Ability to Create, Read, Update (Edit), and Delete records in real-time.

## Features
* **Participant Registration & Edit Form:** Collects and updates full name, email address, employee ID, locked department, and shift timings.
* **Strict Validation Rules:** Prevents form submission if invalid data formats or blank entries are detected.
* **Read-Only Field Constraint:** Secures the airport department field ("Aviation Office") from unwanted modifications.
* **Dynamic Directory List:** Displays all records with instant counter tracking, edit capabilities, and deletion controls.
* **Modern Responsive Interface:** Styled with CSS gradients, keyframe animations, hover elevations, and alert feedback systems.

## Technologies Used
* **React (JavaScript Library):** Component state management and hooks (`useState`).
* **HTML5 & JSX:** Semantic structural markup.
* **CSS3:** Advanced styling, Flexbox, transitions, and keyframe animations.
* **Visual Studio Code:** Development workspace and source control management.
