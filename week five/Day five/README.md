# IIAP IT Internship - Day 4 Backend Mock API

## Overview
Developed as part of the IT Web Development Internship at the Pakistan Airports Authority (Islamabad International Airport - IIAP). This project covers Day 4 backend fundamentals including simple Node.js scripts, JSON handling, parsing request bodies, HTTP status codes, and building a JSON-based Mock API.

## Topics Covered
- **Simple Scripts**: Writing and executing backend scripts using Node.js runtime environment.
- **JSON Format**: Using JavaScript Object Notation for data structure and interchange.
- **Node.js HTTP Server**: Creating custom servers using Node's built-in `http` module without external frameworks.
- **Sending & Parsing JSON**: Serializing responses with `JSON.stringify()` and parsing incoming streams with `JSON.parse()`.
- **HTTP Status Codes**: Implementing proper responses (`200 OK`, `201 Created`, `400 Bad Request`, `404 Not Found`).
- **Hands-on Mock API**: Managing an in-memory JSON database array supporting GET and POST endpoints.
